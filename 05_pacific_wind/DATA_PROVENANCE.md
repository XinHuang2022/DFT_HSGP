# Pacific wind data provenance

The analysis files `ncepu.dat` and `nceplatlon.dat` are the extracted Pacific
wind matrix and ordered site coordinates used by the established MATLAB
implementation. The data contract is 480 time points by 289 sites on a
17-by-17 grid, with a six-hour sampling interval.

Only the analysis-ready files are retained here. Before public release, the
original NCEP/NOAA source, download record, licence, and required attribution
should be confirmed and stated in the repository documentation.
