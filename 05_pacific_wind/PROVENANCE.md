# Pacific code and result provenance

The fixed-rank source was copied from
`deliverables/pacific_wind_eq9_suite_v0_3_1_hsgp`. The preserved fixed-rank
tables come from the completed `full17_cv5_hsgp_cv` run. The adaptive source
and retained summaries come from
`deliverables/realdata_adaptive_hsgp_v0_1_0/Results_extended_relaxed/pacific`.

The release edits localize data and output paths and add package entry points.
They do not redefine the covariance model, DFT convention, Whittle objective,
mean design, coordinate scaling, folds, parameter bounds, or rank criteria.
